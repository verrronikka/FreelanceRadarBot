# Реестр источников FreelanceRadar

Документация проекта (раздел «Открытое решение перед Sprint 2») требует для каждого источника
зафиксировать: URL документации/API, лимиты, разрешённый интервал опроса и владельца доступа.
Без этой записи источник не подключается.

Постоянные источники описаны ниже. Источники, которые пользователи добавляют из бота,
записываются в базу автоматически (кто добавил, когда, тип, адрес), а актуальный список
выгружается командой:

```
python -m bot.sources_report          # печать в консоль
python -m bot.sources_report --write  # обновить файл sources_registry.md
```

## Правила подключения

| Правило | Как соблюдается |
|---|---|
| Только разрешённые каналы: официальный API, RSS или страница, которую площадка разрешает читать | При добавлении из бота проверяется robots.txt площадки; при запрете источник не подключается |
| Без обхода CAPTCHA и антибот-защит | Ответ 401/403 → источник не подключается; при 401/403 в работе — источник ставится на паузу (SOURCE_ACCESS_DENIED) |
| Не чаще одного запроса в 30 с | Интервал опроса ≥ 60 с для внешних сайтов, ≥ 30 с для API с явным разрешением |
| Уважать лимиты | 429 → пауза по Retry-After или экспоненциальная (до 1 ч), SOURCE_RATE_LIMITED |
| Без доступа к локальной сети | Адреса localhost и частных сетей отклоняются |
| Хранение текста заказа ≤ 30 дней | Тексты старше JOB_RETENTION_DAYS очищаются автоматически |

## Постоянные источники

### 1. Example (демо)

| Поле | Значение |
|---|---|
| Код | `example` |
| Тип | встроенный генератор тестовых заказов, внешних запросов нет |
| Документация | `bot/adapters/example.py` |
| Лимиты | нет |
| Интервал опроса | `POLL_INTERVAL_SECONDS` (по умолчанию 60 с) |
| Владелец доступа | команда проекта |
| Включение | `DEMO_SOURCE_ENABLED=true` |

### 2. Freelancehunt (официальный API v2)

| Поле | Значение |
|---|---|
| Код | `freelancehunt` |
| Тип | REST API, `GET https://api.freelancehunt.com/v2/projects` |
| Документация | https://apidocs.freelancehunt.com |
| Авторизация | персональный токен (`Authorization: Bearer`), выдаётся на https://freelancehunt.com/my/api2 |
| Лимиты | общий лимит запросов на токен; текущие значения в заголовках `X-Ratelimit-Limit` / `X-Ratelimit-Remaining`, превышение → 429 |
| Интервал опроса | 60 с (1 запрос в минуту) |
| Владелец доступа | владелец токена `FREELANCEHUNT_TOKEN` (участник команды, указать ФИО) |
| Включение | задать `FREELANCEHUNT_TOKEN` в `.env` |

### 3. Источник A (RSS из `.env`)

| Поле | Значение |
|---|---|
| Код | `source_a` |
| Тип | RSS/Atom-лента |
| Документация / правила | заполнить: ссылка на условия использования площадки |
| Лимиты | заполнить |
| Интервал опроса | `POLL_INTERVAL_SECONDS` |
| Владелец доступа | заполнить |
| Включение | `SOURCE_A_BASE_URL`, `SOURCE_A_NAME` |

## Проверенные площадки

| Площадка | Что проверено | Итог |
|---|---|---|
| FL.ru, RSS (`https://www.fl.ru/rss/...`) | robots.txt: `User-agent: *` → `Disallow: */rss/*` — RSS-ленты закрыты для ботов | не подключается; уже добавленная лента автоматически ставится на паузу |
| FL.ru, страницы проектов (`/projects/`) | robots.txt разрешает | можно пробовать добавить страницу со списком проектов; если список строится скриптом или сайт ответит 403 — не подключится |
| Freelancehunt, веб-страницы (`/jobs/...`) | ответ 403 для автоматических запросов | только через официальный API (п. 2) |
| Хабр Фриланс | правила для обычных ботов не проверены | бот проверит robots.txt сам при добавлении |

Проверка robots.txt в боте работает по стандарту RFC 9309 (шаблоны `*` и `$`, приоритет самого
длинного правила) и повторяется для каждого пользовательского источника раз в 6 часов.
